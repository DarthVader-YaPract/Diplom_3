# Diplom_3

UI-тесты Stellar Burgers для Google Chrome и Mozilla Firefox.

В проекте восемь обязательных сценариев. Каждый сценарий запускается в двух
браузерах, поэтому pytest собирает 16 тестов. В каждой тестовой функции один
финальный `assert`.

## Установка

```bash
pip install -r requirements.txt
```

Команда устанавливает pytest, Selenium, requests и адаптер Allure. Chrome и
Firefox должны быть установлены на компьютере. Совместимые драйверы браузеров
Selenium подбирает автоматически.

## Запуск

```bash
pytest
```

Окна Chrome и Firefox отображаются во время прогона. Результаты Allure
сохраняются в `allure-results`.

Для открытия отчёта выполните:

```bash
allure serve allure-results
```

## Реализация

- элементы и действия описаны через Page Object;
- пользователь создаётся перед тестом через API и удаляется после него;
- Firefox использует JavaScript drag-and-drop;
- оформление заказа ожидает замены временного номера `9999`;
- обновление счётчиков и появление заказа в разделе «В работе» проверяются с
  явным ожиданием.
